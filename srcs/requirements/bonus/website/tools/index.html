Docker Compose Stack

Inception — Service Overview

Quick glance at services running in this deployment.

Services

Nginx

Reverse proxy and TLS entry point for the stack.

port: 80 / 443

WordPress

PHP application serving the site content.

port: 9000 (php-fpm)

MariaDB

Primary relational database for WordPress.

port: 3306

Redis

In-memory cache for sessions and object caching.

port: 6379

Adminer

Lightweight DB management UI.

port: 8080

Caddy

Static file server used for the bonus/static site.

port: 8080 / 443

FTP Server

File transfer service for uploads and maintenance.

port: 21

Monitoring

Observability/metrics endpoint for health checks.

port: 9090

Architecture

  • Edge: Nginx handles public traffic and TLS.
  • App: WordPress (PHP-FPM) serves content.
  • Storage: MariaDB for persistence; Redis for cache.
  • Ops: Adminer, FTP, Caddy, and Monitoring for operations.
