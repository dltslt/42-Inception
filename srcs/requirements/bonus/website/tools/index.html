Docker Compose Stack

Inception — Service Overview

Quick glance at services running in this deployment.

Services

Nginx

Reverse proxy and TLS entry point for the stack.

port: 443

WordPress

PHP application serving the site content.

port: 9000 (php-fpm)

MariaDB

Primary relational database for WordPress.

port: 3306

Redis

In-memory cache for sessions and object caching.

port: 6379

Adminer

Lightweight DB management UI.

port: 8080

Caddy

2nd layer reverse proxy for all other pages.

port: 8443

FTP Server

File transfer service for the WordPress volume.

port: 21 (passive: 21000-21010)

Portainer

Docker container & stack management UI.

port: 9000

Architecture

  • Edge: Nginx handles public traffic and TLS, routing by SNI.
  • App: WordPress (PHP-FPM) serves content.
  • Storage: MariaDB for persistence; Redis for cache.
  • Ops: Caddy (2nd-layer proxy + this static site), Adminer, FTP, and Portainer for operations.
